# 专注日历

基于方案 2 的 Windows 桌面任务日历，包含完整模式和迷你模式。

## 已实现

- 任意未来日期创建日、周、月任务。
- 已完成任务保留在列表底部，显示删除线并可恢复。
- 快速添加只需输入任务名称，默认加入当前选中日期。
- `后续安排`自动显示最近的未来未完成任务，无内容时自动隐藏。
- `后续安排`每 4.5 秒纵向轮播，悬停暂停，并支持鼠标滚轮切换。
- 支持每周和每月循环任务；每期生成独立任务并保留历史完成记录。
- 循环任务支持仅修改/删除本次，或修改整个循环/停止后续循环。
- 任务编辑器明确区分“任务归类”和“重复频率”；选择每周/每月重复时自动联动对应归类。
- 启动时会集中处理过期未完成任务：顺延到今天、保留原日期或标记放弃。
- Windows 通知支持直接完成、15 分钟后提醒或明天提醒。
- 程序记录上次提醒检查时间；Windows 从休眠恢复或解锁后，会补发休眠期间到期且仍未完成的提醒，并避免重复弹出。
- 设置中支持导出/导入 JSON 备份，并可直接打开本地数据目录。
- 新增约 480×320 的超迷你模式，仅保留日期、未完成任务和快速添加。
- 设置中可在中文和 English 之间切换，用户输入的任务内容保持原样。
- 任务时间和提醒均为可选项；提醒支持 Windows 系统声音。
- 窗口透明度、置顶/普通/桌面层级、锁定位置、鼠标穿透、迷你日历和开机启动设置。
- 鼠标穿透开启后可按 `Ctrl + Shift + X` 恢复操作。
- 本地离线保存、完整模式/迷你模式切换。
- 完整模式、迷你模式和超迷你模式三级切换。

## 直接使用

从 GitHub Releases 下载 `FocusCalendar-Setup-x.y.z.exe` 并安装。应用启动后会在后台检查新版本；发现更新后可在设置中下载，并在下载完成后重启安装。

断网或更新失败不会影响应用正常使用。任务和设置保存在当前 Windows 用户的应用数据目录中，升级和普通卸载不会删除这些数据。

## 开发

```powershell
npm install
npm run desktop
```

构建网页资源：

```powershell
npm run build
```

构建 Windows NSIS 安装版：

```powershell
npm run desktop:build
```

## 发布新版本

1. 同步修改 `package.json` 和 `package-lock.json` 中的版本号。
2. 提交代码并创建同版本标签，例如 `v1.0.3`。
3. 推送标签后，GitHub Actions 会构建安装包并发布 GitHub Release，同时上传自动更新所需的 `latest.yml` 和 blockmap 文件。

如果在非 NTFS 工作区遇到 Electron 打包临时目录重命名错误，可将 electron-builder 输出临时指向系统盘，再把最终 EXE 复制回 `release-final`。
